# Implementation Plan: Validated Research Job Configuration

**Branch**: `gh-issue-3` | **Date**: 2026-10-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-gh-issue-3/spec.md` (GitHub issue #3)

## Summary

Define the research job contract as immutable, strictly validated Pydantic v2 models in
`src/invio/config/job.py` (schedule, notification, five source kinds as a discriminated union,
search, LLM, limits, schema version), with YAML load/save that is lossless and immune to
YAML 1.1 surprises (`17:30` → int, `on` → bool), a single `JobConfigError` carrying
operator-readable `<field.path>: <message>` lines, a generated JSON Schema at
`docs/job.schema.json` with a staleness test, and stdlib-only shared records
(`Candidate`, `ProcessedItem`) in `src/invio/domain.py`.

## Technical Context

**Language/Version**: Python 3.12 (uv-managed)

**Primary Dependencies**: Pydantic v2 (existing), PyYAML (new runtime, already locked
transitively), email-validator via `pydantic[email]` (new runtime); dev: `types-PyYAML`,
`jsonschema`, `types-jsonschema`

**Storage**: Files — YAML job files; generated `docs/job.schema.json`; reference example
`docs/job.example.yaml`

**Testing**: pytest (existing; autouse fixtures isolate settings/env)

**Target Platform**: Linux (cron/systemd) and macOS dev; system tz database via `zoneinfo`

**Project Type**: CLI application / library modules (single project)

**Performance Goals**: None — loading a job file is not a hot path (informational only)

**Constraints**: No network or DB access during validation (e-mail check without DNS);
`mypy --strict` clean; domain module stdlib-only

**Scale/Scope**: ~350 LOC source, ~500 LOC tests; 2 new modules, 2 docs files

All unknowns resolved in [research.md](./research.md) (R1–R12); no NEEDS CLARIFICATION remain.

## Implementation Notes (for /speckit-tasks)

- Order: dependencies → domain (independent, unblocks other tracks) → enums/base model →
  section models → sources union → JobConfig → YAML loader/dump + `JobConfigError` → example +
  schema → README.
- Error loc rendering: drop the union tag segment that follows a list index under `sources`
  (`('sources', 2, 'rss', 'url')` → `sources[2].url`).
- Pydantic runs model validators only if field validation succeeded — tests for cross-field
  messages must use otherwise-valid input.
- `HttpUrl` normalisation (trailing slash on bare host) is acceptable; round-trip compares
  models, not file text.
